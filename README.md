# To-Do List Application (Python)
The To-Do List Application is a Python-based program that allows users to create, view, and delete tasks. It helps users organize daily activities using a simple menu-driven interface and follows the Software Development Life Cycle in its development

This project is a simple command-line To-Do List application written in Python.  
It allows users to:

- Add new tasks  
- View all tasks  
- Delete tasks  
- Exit the application  

##  Features

- Add tasks to a list  
- Display all saved tasks in numbered form  
- Delete a task by its number  
- Handles empty task lists gracefully  
- Runs continuously until the user chooses to exit  

---

## Project Structure
TO-DO LIST APPLICATION

1.Add Task

2.View Tasks

3.Delete Task

4.Exit

If you choose 1, the program will ask you to enter a new task and save it.  
Example:
Enter a new task: Do homework
Task added successfully.

If you choose 2, the program will display all your tasks in a numbered list.  
Example:
Your Tasks:
1 Do homework
2 Read a book


If you choose 3, the program will show your tasks and ask for the number of the task you want to remove.  
Example:
Enter task number to delete: 1
Task deleted successfully.


If you choose 4, the program will stop running and exit.
